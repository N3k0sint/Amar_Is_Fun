# SPRM Quest: The Officer's Journey

**SPRM Quest** is a cross-platform educational game designed to train and test the integrity of future SPRM (Malaysian Anti-Corruption Commission) officers. 

Players take on the role of a recruit navigating the challenges of public service, making ethical decisions, and investigating corruption cases in a high-stakes digital environment.

---

## ✨ Key Features

*   **Procedural Maze Investigation**: A unique maze generation algorithm (Recursive Backtracking) ensures every investigation mission is different and fully solvable.
*   **Ethical Scenarios**: Interactive branching narratives that test the player's understanding of MACC/SPRM laws and anti-corruption principles.
*   **Cross-Platform Performance**: Fully optimized for **Desktop (Windows)**, **Mobile Phones**, and **Tablets**.
*   **Adaptive Controls**: Responsive on-screen D-Pad for touch devices and Keyboard support (Arrows/WASD) for desktop.
*   **Premium Aesthetics**: Sleek dark-mode interface with official SPRM branding and Orbitron typography.

---

## 🎮 The Missions

1.  **Mission 1: The Briefing**: A high-pressure quiz on the history and legal framework of anti-corruption in Malaysia.
2.  **Mission 2: The Investigation**: Navigate a complex labyrinth to recover sensitive evidence files.
3.  **Mission 3: The Prevention**: Identify and stop a bribery attempt in a procurement scenario.
4.  **Mission 4: The Gift Dilemma**: Decide the ethical course of action when faced with "gifts" during festive seasons.
5.  **Mission 5: The Reporting**: Learn how to correctly report corruption via official channels.

---

## 🛠️ Technical Stack

*   **Core**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
*   **Engine**: Custom Canvas Engine for 2D Maze rendering.
*   **Desktop Wrapper**: Electron
*   **Mobile Wrapper**: Capacitor.js
*   **Build System**: Gradle (Android) & Electron-Builder (Windows)
